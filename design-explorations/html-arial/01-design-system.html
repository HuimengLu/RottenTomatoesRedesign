ROTTEN TOMATOES · DESIGN SYSTEM · ARIAL EDITION
Foundations
Built on Pentagram’s Rotten Tomatoes identity: a chunky custom wordmark, flat score icons with no outlines, one loud red on lots of white and light grey. Interface type is Arial only, so hierarchy comes from size, case and colour, not from extra weights.
Red is a signal
Brand Red marks the brand, Fresh, and the one primary action in view. Never decoration.
Flat and bold
Icons are solid shapes, no strokes or gradients. Weight and size carry hierarchy.
Content first
Review text is the largest text in a card. Names, outlets and dates are metadata.
01
Logo

Clear space equals the height of the tomato. Minimum width 88px in a web header. Never recolour the splat or tomato on dark: use the all-white lockup.

Direction tweaks
One system, four skins. These are the only places a direction departs from the shared tokens, and why.
A
Reel
THEME
Dark theme: Ink / Panel / Projector White (#F6F1E7). Warm white instead of pure white keeps the cinema feel.
TYPE
Arial Bold is narrower than the original wide display, so the hero loses some scale. Option: allow Arial Black for the hero title only.
COLOUR
Stars and highlights switch to Popcorn Yellow; muted text never below 50% alpha (5.3:1).
COMPONENTS
Ghost buttons and icon buttons on dark; ticket bar = compact score + tabs + Action Red CTA.
B
Poster Tint
THEME
Generated per film: background L 20%, surface L 26%, chip L 33% from the poster hue, chroma capped.
COLOUR
Muted text raised from 45% to 60% alpha: 45% measured 3.8:1 on cards and failed AA.
COMPONENTS
White pill buttons (Douban pattern) carry the Action Red / amber icon; ads sit in a neutral grey slot outside the tint.
TYPE
No change: Display M title, H2 section titles, Body L reviews.
C
Verdict
THEME
Closest to the Pentagram default: white + Gray 100 surfaces, black type.
COLOUR
Header and primary buttons move to Action Red: white nav text on Brand Red was 3.8:1. Blue links are removed; links are Black Bold with an arrow.
COLOUR
Stars use Amber 700 on light (Popcorn Yellow is 1.4:1 on white).
COMPONENTS
PARTNER tag on Fandango at Home plus an ownership note above the price table.
D
Broadsheet
THEME
Warm paper #F7F4EE replaced by Pentagram Gray 100 so D shares the brand neutral.
LOGO
Full-colour lockup (black, green splat, red tomato) centred in the masthead.
TYPE
Display XL needs −4px tracking in Arial; rules are 2px Black for sections, 1px Gray 200 for columns.
OPTION
Pentagram’s graph-paper texture can back section openers for an editorial notebook feel.
Why Arial, and what it costs
Arial is installed everywhere, so files open the same on every machine and the Figma file needs no font replacement. The trade: only two weights, and wider letterforms than Franklin Gothic. Long labels were checked for overflow; hierarchy now relies on size and case. For production, keep these tokens and swap the family back to RT’s licensed fonts.
